# 固件入口

`main.c` 使用固定共享 SRAM 地址读取 M、N、shift 及输入指针，调用公共 `kwt1_run` 驱动。回调通过 volatile 32 位访问及 `fence iorw,iorw` 访问加速器寄存器。

生产驱动只搬运数据和执行控制：不计算矩阵，不读取参考答案，不分配动态内存。输出按硬件逐行返回，读完该行的每项数值与 flags 后才 ACK。

编译使用 RV32IMAC、ILP32、独立启动汇编和链接脚本。ELF、map、反汇编、ISA 属性、bin、hex 和确切命令随验证结果保存。main 返回码由启动汇编写入邮箱；任何非零返回、TRAP、缺少输出、超时均使系统验证失败。

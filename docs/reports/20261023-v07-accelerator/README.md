## 试综合范围

使用本地`TS1N28HPCPL2SVTB2048X32M4MWBASO_tt1v25c.lib`作为SRAM库，12颗宏全部保留。每颗2048×32=8KiB，总物理实例容量96KiB；W的逻辑载荷虽只有4KiB，不能按4KiB计宏面积。

Yosys `synth -noabc`及`check -assert`通过。通用门级统计：61165 cells，含5007个$_DFF_P_和12颗SRAM宏；其余为通用AND/OR/XOR/NOT/MUX。未做标准单元映射、时钟约束、STA或功耗估算，不用通用门数推算正式mm²。

Yosys有两类预期警告：短的data_pipe/mask_pipe数组被转换为寄存器列表。这里是延迟寄存器，不是把X/W SRAM展开为触发器；最终12颗宏计数另行检查。

## 警告与限制

- 实际宏UNIT_DELAY模型在仿真0时刻报CEB初始化/退出shutdown顺序警告。未屏蔽警告，未修改宏模型；正常加载、运行、复位及中止流程功能比对通过。上电/睡眠/关断时序不在本版验收范围。
- 当前matrix_ctrl一次一个读请求在途，返回暂存后再供数；行为RAM一拍延迟时稳定供数间隔约3拍，两拍延迟约4拍。尚未实现每拍一组的预取优化。
- 没有64项结果缓冲，输出背压会延长当前块占用时间；这是已确定的初版组织。
- 独立输出握手表示接收方消费；未来SoC实际写回完成仍需总线层协议。

## 审阅与修正

独立只读审阅检查模块边界、槽释放、标签、尾行、背压和中止；指出完成周期BEGIN语义及测试缺口。新增测试先复现完成当拍BEGIN误报fault，再修正frontend与busy；补充连续命令、计算/受阻输出阶段协议故障取消测试，随后重跑完整12层。

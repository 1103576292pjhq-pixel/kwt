## 冻结后完整验证划分

- 原模型十二分类验证索引共 4445 条记录，实际计算 4075 个不同输入；一个全零波形按 371 条原始静音记录加权。
- 十二层最差汇总 NRMSE 为 **0.0211055%**；最差单输入、单层矩阵任务为 **0.0319907%**。
- 输入、输出、累加和偏置饱和计数全部为零，所有部分和界证明安全。
- 模型 162 个实际参数张量与 checkpoint 核对一致。

NRMSE 由平方误差和参考能量计算，不是分类错误率。4445 是原模型十二分类划分记录数，不是整个 35 词原始验证 WAV 数量。未用测试音频调参。

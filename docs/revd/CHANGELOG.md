# RevD 相对 RevC

本轮不是再增加一套大而全架构，而是核对并吸收用户提供的外部评价。

1. 新增逐项审查：TensorFlow/PyTorch、ICB/NICE、已存在的复用对照、FP32真实时序结构、门槛/得分。
2. 保留4×4/CTX4/权重分块主线，明确FP32作为扩展基线保留；未来本科提交top只例化所选新整数引擎，不同时计入未用扩展硬件。
3. 对“2块16×4096放输入”不简单否定：新增2个X存储体+双向量保持寄存器的XP2，利用CTX4每4拍消耗一组四行输入的节奏进行两拍预取。
4. 不将2个宏当成完整编码器所有工作存储；明确X、Y、K、V、残差、hidden等生存期和带宽。
5. 将未来算子统一拆为公共乘加原语、可跨K分段的未截断部分和、矩阵地址生成、算子专属后处理，而不是复制dot64的32位最终输出相加。
6. 新增精度公式工具：3%是准入门槛而非满分；Top-1用个百分点。当前位宽不变，INT8/逐通道标定列为后续条件任务。
7. 补充有序输入流的队首等待约束：V2仅tile0在START前预载；数据消费者和结果接收并发，避免等待空槽的未来OPEN挡住START。
8. 原19项软件测试保留；新增17项测试。工具只验证软件例子和规格模型，不改称RTL验收。
9. 新增离线HTML与两页架构图，原RevC作为来源而不是另一个并列“最终版本”。

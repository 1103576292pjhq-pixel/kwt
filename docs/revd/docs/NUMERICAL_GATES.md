# 数值精度：保持正确性，还要保留得分余量

来源是用户上传指南，不把以下示例当正式成绩。[S01]

## 1. 本科NRMSE

每层汇总所有样本的全部输出元素后，计算：

`NRMSE = sqrt(sum(error²)/N) / max(sqrt(sum(reference²)/N), 1e-8)`。

最后取12层最大值。不能平均每个样本的NRMSE，因为参考能量不同。正式12个性能任务还须分别满足3%门槛。

以比例r表示误差：精度分为`max(0, 10-r/0.003)`。例如0.003是0.3%，得9分；0.03是3%，得0分。不能把3%叫满分精度线。

更低的内部目标可以提高得分余量，但属于工程选择而非官方新增门槛。当前结构优化保持完全相同的数值合同，必须零位差，不能用NRMSE容差掩盖RTL错误。

## 2. 研究生Top-1

使用同一数据集与同一分类头：`drop_pp = 100*(reference_correct - candidate_correct)/sample_count`。

准入要求drop_pp≤2，精度分为`clip(10-drop_pp/0.2,0,10)`。570/600降至558/600是下降2个百分点，不是相对下降2%；该项得0分但恰在数值门槛。

`precision_metrics.py`用整数计数/Fraction进行Top-1边界判断，避免二进制浮点把精确的2个百分点误判为大于2。

## 3. 分离数值阶段和架构阶段

架构A/B只改变并行调度/缓存，不改变X/W/b/scale/shift，参考输出应一样。INT8/逐通道/非线性替换另开数值配置，先软件评估。不同数值配置的精度、时延、功耗必须完整绑定，不拼接最优结果。

模型来源是指定TensorFlow实现及权重。Python定点参考不是用gcc编译的；C参考的禁止自动收缩与显式fmaf同时存在，保持既定操作顺序。[S04][S05][S07][S08]

## 4. 数据集使用

训练划分：无梯度标定。验证划分：调试与精度验证。测试划分：不得用于调权重、量化参数或配置。记录样本身份、划分、选取规则、原始数据及提取数组摘要。

600条正式评测清单评测后才公布，不能等待一个指南没有承诺发放的预处理包，也不能把自选600条称为官方600。当前仓库3输入/36层FFN1结果和15输入完整编码器只是工程覆盖。[S01][S11]

## 5. 工具边界

包内工具对合成数值和公式进行测试，不生成真正的标定尺度，不判断官方样本精度，也不授予官方分数。遇到非有限值、空输入、长度不匹配应失败；不删样本、不裁掉异常输出来获得PASS。

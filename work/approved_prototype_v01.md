## 固定工程基线

首版单 MAC，X/W 有符号16位，乘积32位；先累积64个乘积，再加48位偏置；偏置相加采用49位临时值检测，原始和饱和为48位并报告 overflow，禁止回绕。输出为有符号32位，经非负右移、最近偶数舍入（RNE）、最终饱和得到。支持 shift=0..47，其他值拒绝并明确错误。DOT64 允许输出48位 raw sum 作调试，但正式32位数值处理必须在RTL中。

Python 逐位参考使用明确的整数运算，独立手算用例检查；不得用 NumPy 类型自然溢出模拟规格。

不做样本驱动参数优化或训练。为避免拿 validation smoke 选尺度，本版固定：

1. 输入步长 `sx = 2^-8`，所有层一致，编码 `Qx = sat16(RNE(X/sx))`。
2. 每层权重步长 `sw=2^e`，由该层冻结的完整 W 最大绝对值直接推导最小可覆盖的2幂步长；保证 `maxabs(W) <= 32767*sw`，W全零时sw=1。此步骤是确定性范围计算，不是样本或性能搜索。
3. `Qw=sat16(RNE(W/sw))`；`Qb=RNE(b/(sx*sw))` 必须适配48位；转换器计算保守边界 `64*32768*maxabs(Qw)+maxabs(Qb)`，超48位则拒绝并报告。
4. 输出右移 r 由该保守整数边界确定，以 RNE 后不超过正int32上限为条件直接计算最小非负r；r<=47。`Qy=sat32(RNE(raw48/2^r))`，解码系数严格为 `sy=sx*sw*2^r`。
5. 每层尺度/移位固定于全部输入，不按样本调整；不以现有validation输出挑选或反复修改尺度。若浮点误差超3%，真实报告，不能悄悄改参数、改数据或声称正式达标。
6. 输入/权重/偏置/累加/输出的超范围、RNE半值、零输入、全零权重均有显式行为和计数。例：r=1时3→2、5→2、-3→-2、-5→-2；r=0原值保留后再按位宽饱和。

## 存储与整矩阵控制

- 当前一套X/W/b驻留，Y只缓存一行256个32位结果；遍历m=0..98、n=0..255、k=0..63。
- X行主序；W可打包为`W_pack[n][k]=W[k,n]`以简化连续64项读取；偏置按n排列；结果按m/n输出。只做重排，不改变模型数学形状或运算归属。
- 行为存储必须有明确同步读延迟，读写分时且经wrapper。禁止组合读取大型数组来掩盖实际读延迟；不逐字复位全部RAM。首版允许合理的分银行实现，但不声称已经映射真实宏或面积达标。
- load_begin清本任务装载计数和有效标记，按文档公开接口装载X/W/b；完整装载前不能START。运行期间不能破坏本任务数据。初版可强制顺序装载，以计数确认完整性，避免巨大的逐字有效位图。
- 每行全部结果实际写入完成才ROW_READY；等待ACK时BUSY为真、行号及数据保持。ACK绑定当前行，只能有效消费一次。最后一行ACK后DONE。外部可以任意停顿，测试设明确超时假设，不假设消费者永不阻塞。
- 复位中止任务，清控制与有效标记；要求重新装载，禁止旧行/旧DONE污染下一任务。连续任务和12层参数切换必须验证。
- 最终模块提供平台无关装载、启动、状态、行读取和ACK接口；选用一致、可文档化的端口协议并冻结，暂不声称是E203 MMIO。

# KWT RevD/V2 本地候选与资格证据

本轮默认候选为 **full-W、CTX4、PM4×PN4、Y1**。它保留原数值契约，并取得新核自身的真实 E203/C 驱动、索引写回和冷切参证据。W1/W2 的容量与前端周期优势分别保留为备选；其 CPU 范围以最终 `SUMMARY.json` 为准。

本科权重为功能数值40、SoC/综合/复现20、吞吐8、单任务能耗8、面积4、创新20。后40分受全部必做、数值与位真、150 MHz、面积≤2.25 mm²资格门约束。正式600样本、所选12任务、指定工艺资料和其他合格队伍极值均缺，本文不给比赛分数。

## 实现与不可变契约

公开事件流 → 单事件队列 → 同步 X/W RAM 请求及返回标签 → 乘积寄存器 → 四个48位累加上下文 → 49位加偏置 → sat48 → RNE → sat32 → 持有 Y/flags → CPU 按 `m*N+n` 写共享 SRAM → 最后写响应确认。

- 输入与权重固定 signed16。每个结果精确累加64项；偏置相加保留49位。右移范围0..47，最近偶数舍入；raw溢出和输出饱和分别保留。
- CTX4 对同一 k 依次发射四个列组，g0取得的有效行 X 向量供g1..3复用。k/g/行掩码/task/valid随真实同步返回流水；最后乘积退休后才量化。
- 末输出保持期间及完成脉冲边界保留入口屏障。此前已接受的非法事件仍必须退休为故障，不能被成功完成掩盖。
- W1 只预载tile0后START；W2使用两套独立SP bank。两槽占满时下一OPEN可以被事件队列接受而尚未退休，CPU仍需公平排Y。COMMIT表示槽就绪；owner释放等旧tile最后Y握手及最后bias引用完成。
- 数据通路不使用TB私有RAM写入、force或CPU数值代算。raw48通过公开单元或被动内部trace核验，不虚构顶层raw字段。

full-W PM4 L1前端冷周期减少49.2009%，其START至末Y窗口从388361降至183350。实际 X read CE 从405504降至101376；W read CE仍为409600。退休有效MAC均为1622016，PM4 issue/retire为102400，尾行虚拟lane MAC为16384。CE减少不等于已测能耗减少。

W1与full-W的冷窗只差40周期，不能据此宣称吞吐显著提升。W1/W2之间还核过逐字相同的公共命令与实际输出SHA；W2 L1相对W1减少19178周期。W2生产的实际跨独立SP bank读写同拍、issue与写同拍、MAC退休与写同拍均为9360；15360仅为processing阶段写入数，不能混称有效读写重叠。同拍COMMIT退休/旧tile末Y另有L1/L2定向命中证据。

真实CPU对照使用相同公开E203、ICB、C固件、共享内存镜像与响应策略，运行冻结输入的前两层：D2冷窗5910423/5910421，CTX4 PM4为5708000/5707998，各省202423周期，约3.42485%。该窗口包含CPU向核装载X/W/bias、CPU/总线等待及最后共享写响应；不含音频前处理、主机安装初始共享镜像或CPU启动。窗口采用包含端点的 `last_response-cold_start+1`。这不是正式平台吞吐，也不是拿旧FP32 encoder周期作分母。

固件在任务marker前读取全局M/N/count三个header字，未计入上述窗口；每任务layer、shift、地址描述符及全部X/W/bias在marker后读取。报告保留这个实际边界，不把它称为从程序第一条参数读取起算的正式赛事窗口。

W2另以真实E203执行相同前两层，冷窗为5263449/5263447，各比full-W PM4减少444551周期，即7.7882%。公共输入、索引写回、全部Y/flags和响应策略一致；C驱动只因分块生命周期调整START位置。两槽占满的未来OPEN累计延迟1937018周期，期间CPU完成16542次Y POP，证明供给与排空实际交错推进。W2还完成独立双tile非零flags定向例，192个Y/flags覆盖四种标志组合，并实际拒绝错overflow位。该范围是两次完整冷任务，尚未扩展到12层CPU；full-W默认候选保留12层CPU覆盖，W2作为已验证备选保留，不据逻辑容量和周期宣布物理赢家。

PM2真实CPU冷窗为5809223/5809221，比PM4增加约1.7734%。更少的乘法器没有在此CPU窗口中胜出，不能以理论MAC数量代替实测选择。

## 资格和验证范围

每个完整core36为3个工程输入×12独立层，共912384个唯一输出；两个实际validation WAV均为unknown，第三个为合成静音。每层读取自己的冻结输入，不把上一层FFN1结果冒充下一层输入。局部按层合并SSE后的最坏NRMSE为0.0009342248801263425；这不能替代正式600样本。

验证覆盖全部48 shifts、signed边界、k63-only、尾3行、连续改参、在途复位、有限停顿、payload/标签稳定、最后输出附近非法已接受事件及下一BEGIN。默认核有6类实际编译RTL变异，薄适配3类，W1为8类、W2为10类；不按PM/延迟重复计类数。软件证据负测与实际错误C程序另计。红测和修复绿测的入口由最终SUMMARY索引。

CPU层集合、非零overflow/saturated组合及可选W2薄集成的实际完成范围以SUMMARY为准。六次双任务boot覆盖12层时，仍明确是六次boot中的12个冷任务，不冒充单次12层连续boot或完整encoder。

## 工艺与提交缺口

Yosys只执行保留存储器的粗综合与结构检查，未执行memory_map、ABC、指定工艺映射或STA。full-W PM4的通用cell计数748，W1为780，W2为916；这类未映射计数不能换算mm²。对应推断存储数据位为382080、124800、142020，还需单列控制寄存器、接口和物理映射成本。

允许的16位深度128/1024/4096组合及端口、padding分账见 [宏组合候选账本](macro_combination_candidates.json)。W1/W2的逻辑256深度不能冒充指定256深度宏；bias、累加器、Y/flags及标签也不能漏计。W2扁平bias数组的跨槽读写不被当作单SP宏已完成映射。

正式提交仍缺指定库/宏模型与面积表、有效目标SDC和映射网表、综合后功能验证、150 MHz STA、≤2.25 mm²面积、完整SoC活动覆盖和功耗/能耗、正式600/12评测及答辩材料。没有生成占位网表、SDC或功耗文件充数。当前包是本地可复现候选，不代表组委会验收。

复现入口、依赖、当前源码/运行SHA、选择理由与逐项状态见候选包README/PACKAGE及本轮SUMMARY；冻结基线、失败与未采用结果保留原位，不改旧接受记录。

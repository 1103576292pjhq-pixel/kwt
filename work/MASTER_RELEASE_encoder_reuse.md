# MASTER_RELEASE：编码器层间复用对比

状态：RELEASED。用户在本对话明确回答 A“采用这组对比”。总控据此放行，不需要再询问。

决策变量：仅二选一的数据交接策略：A CPU从加速器读回中间激活到共享SRAM，再从共享SRAM重新装入下一层；B 加速器内部X/Y双缓冲交换，直接作为下一层激活。模型算子、权重、数值位宽、运算顺序和并行度均固定，不允许借此扩大为参数搜索。

目标函数：分别最小化真实测量的共享SRAM传输次数/字节与同口径端到端周期；同时报告二者，不虚构单一加权指标，不以只数理想MAC或估算传输代替实际计数。

约束：同一官方KWT-1权重及输入、同一FP32与非线性近似顺序、512KiB共享SRAM、同一CPU/总线/工具版本和时钟、全部输出逐位相等。两方案从等价清缓存/复位状态开始，计时覆盖输入/按层权重载入、CPU/ICB等待、层间调度和最终输出写回。离线预处理/一次格式转换/软件分类头排除。测试host按层更新参数区的边界及是否包含时间必须一致且明列。

输出：真实运行两种策略至少一个相同完整99×64输入各十二层，比较每层及最终6336word全部一致；记录真实CPU状态、总线/共享SRAM/参数访问、周期、哈希、命令/固件/配置；报告绝对值、差值及比例。计数要靠握手/实际load-store，不用形状计算后冒称实测。若墙钟较长，持久运行并提供PID/progress/log，不降级成小尺寸正式结论。

验证读回与性能计时需分开：候选可用只读trace逐层核对而不强制CPU搬回全部中间张量，避免验证流量掩盖复用收益；两方案都只要求最终层输出写回为计时终点。若为额外诊断读回中间层，单列该开销且两方案使用一致规则。

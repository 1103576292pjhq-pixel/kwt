# 给队友的源码交接说明（2026-11-17）

这次先交付服务器核对过的加速器源码和 System Bus 接入修正源码，继续使用16MAC、CTX4、W2/Y2计算架构。这里是源码增量快照，不是已打包完成的独立可运行工程。

## 从哪里看
- `kwt_dma_soc_top.v`：修正后的SoC设计顶层。
- `e203/subsys/`：三个E203子系统修改文件。
- `accelerator/rtl/`：20个加速器RTL及配置头文件。
- `SOURCE_MANIFEST.json`：每个交付文件的SHA256、核对等级及来源。

原分支的历史源码、运行脚本和说明保留。本目录是本次新交付入口；不要把历史目录和本目录递归合并编译，同名模块会冲突。

## 本次修改
CPU和DMA在原有System Bus入口侧仲裁，经过原有 `u_sirv_mem_fab`，从SysMem出口访问共享SRAM。DMA读入和结果写回共用这条32位通路。顶层将DMA的10个请求/响应信号传入E203子系统；仲裁器在存储子系统中完成响应归属管理。计算核心及数值方案本轮未修改。

目标路径：
```
CPU请求 ─┐
         ├─ 主设备侧仲裁 → 原有System Bus → SysMem → 共享SRAM
DMA请求 ─┘
```

## 必须注意的封装文件
`accelerator/rtl/dma/kwt_dma_system.v`为服务器目录中保留的外围封装，其内部CPU/DMA仲裁器直接接共享SRAM，没有实例化原有System Bus。此次按服务器文件清单恢复保留，以便追溯；它不是修正后的SoC顶层，不应因文件名而选作最终接入入口。它在最新测试中的实际实例化情况未单独证明。正式设计入口应从本目录的 `kwt_dma_soc_top.v` 和配套E203子系统检查。

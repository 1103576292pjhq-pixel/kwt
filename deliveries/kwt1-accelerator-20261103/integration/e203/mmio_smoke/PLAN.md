# CPU MMIO 最小验证计划（2026-11-02）

用户已确认：先使用真实 E203 执行测试程序，不接共享 SRAM。沿用现有加速器自定义 ABI，不修改 RTL、原工程、服务器 simv 或 add 基线。使用已验证的本地 Nuclei 2024.06 工具链。

范围：STATUS/ERROR 检查，以及 TASK/LAYER/TILE/INDEX/DATA/ACK_TASK/ACK_SEQ/ACK_COUNT 八个暂存配置寄存器的三组写入/读回。成功 28 次读、24 次写，共 52 次 MMIO。不写 COMMAND、ACK、ABORT，不宣称计算或 SRAM 数据搬运通过。

启动：入口 0x80000000，C/启动正文从 0x80000100；栈顶暂用 ITCM 内 0x80001000，程序和 bss 限制在 0x80000c00 以下，保留至少 1 KiB 栈。编译记录须明确此最小 4 KiB ITCM 使用约定；E203 上游默认容量足够，服务器实际启动能力仍以运行确认。

结束：保留既有 TB 的检测机制，地址 0x80000086 放 2 字节 c.j 自循环。C 返回 1 表示成功，启动代码将返回码写入 x3，再进入循环，TB 观察 8 次此 PC 后判定。异常向量设置到本程序 trap_entry；陷入异常时 x3=0xe0，a1/a2/a3 保存 mcause/mepc/mtval。

实现文件：start.S（启动/清 bss/异常/结束）、link.ld（固定入口/结束/ITCM 布局）、register_test.c（检查逻辑）、real_io.c（volatile 整字 MMIO 与 main）、tests/native.c（检查逻辑的负向测试）、build.py（本地编译/镜像检查/报告）。

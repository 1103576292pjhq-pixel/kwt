# 临时共享 RAM：范围与实现计划

2026-11-02。用户已选择先做临时实现，并要求不影响队友综合。按 brainstorming / writing-plans 流程记录已选择方案，不重新设计加速器。

方案：512 KiB 行为存储，仅用于功能仿真；一个可综合的 ICB 控制器接独立同步存储后端。暂定开发地址 0xa0000000，非赛方确认地址；同域时钟/复位沿用 hfclk/bus_rst_n。未来替换存储后端时保留控制器接口，但最终平台延迟、仲裁、加载接口和地址仍需复核。

隔离：所有新文件放 integration/e203/shared_ram_dev，不改生产 rtl/kwt.f、不改已有计算模块、不覆盖服务器 kwt_soc_top 或已通过的 add 基线。模型不进入综合清单；SYNTHESIS 宏下误编译模型时强制报缺失保护头文件。对全 SoC 的正式综合不提供虚假 SRAM 面积、功耗或时序结论。

语义：32 位 ICB；512 KiB = 131072 个 32 位字；地址按字节寻址，低两位交给 CPU 的字节通路选择，读返回所在完整字；写数据与字节掩码由 CPU 给出。支持一笔在途事务和响应背压；非法窗口地址返回 err=1 且不访问存储。后端同步返回，一次请求在接受沿后的周期返回；无零周期响应。复位清控制状态，不清 RAM 内容；未写区域为未知值。

限制：临时固定单端口，不引入尚未明确的官方 host 接口或双主仲裁，不将预加载视为赛事参数装载计时通过。未来 CPU 与真实加载端共享访问需匹配官方平台。

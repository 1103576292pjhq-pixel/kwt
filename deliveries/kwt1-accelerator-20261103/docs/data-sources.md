## 2. 对RTL的实际用途

原始WAV经过指定版本KWT-1离线推理，提取每层第一FFN线性层的实际输入X、权重W、偏置b和浮点参考Y。随后用本工程encode_finite生成定点输入，由ffn1_int16生成整数黄金；未来RTL逐位对照整数黄金，解码后再与浮点参考比较误差。

原始数据不是RTL直接接收的文件格式，也不是要求把MFCC、注意力、GELU等加入本科必做计算。它的价值是来源可追溯、能生成更多真实验证向量，以及评估当前量化方案的精度。

训练划分仅用于允许的无梯度标定；验证划分用于调试。测试划分不能用于调整尺度或参数。本轮保持已冻结Q12/Q16/Q28和RNE16不变，没有重新标定。

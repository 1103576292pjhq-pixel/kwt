# kwt_storage_wrapper：逻辑bank封装

更新：2026-10-29。源码：[kwt_storage_wrapper.v](../../../rtl/memory/kwt_storage_wrapper.v)。当前已写RTL并完成合同模型自检，官方模型验证待补；[验证证据](README.md#验证结论与证据)。

## 思路与纠正

用户提出“两个SRAM映射为一个bank，读出也两个一组”。这里的一组表示共享一个逻辑地址空间，不是每次同时读两颗再拼接。X的一组深度2048，使用前1600项；W的一组深度256。每次按地址高位选一颗，得到一个16位数据。

返回选择不能直接用当前请求地址：连续访问不同半区时，当前地址可能已经是下一笔。必须在接受读请求的同一上升沿保存part，并用保存的part选择该次Q。

## 对外接口

| 接口组 | X | W | 含义 |
|---|---|---|---|
| rd_en / wr_en | 各4位 | 各8位 | 每bank一位请求；同一bank不能同时读写 |
| addr | 44位=4×11 | 64位=8×8 | 每bank共享一个读写地址 |
| wr_data / rd_data | 各64位=4×16 | 各128位=8×16 | 各bank独立16位写/读字段 |
| rd_valid | 4位 | 8位 | 每bank一位有效返回 |
| access_error | 4位 | 8位 | 每bank一位非法请求报告，非粘滞 |

均为编号0在低位，W总线编号 `wb=slot*4+bank`。clk/rst_n和bias端口与存储实体一致；bias直通，不增加流水级。参数SRAM_EMA=000、SRAM_EMAW=00为首个待验证候选；RET1N固定1。

## 地址和控制的组合逻辑

| bank类型 | part | 宏内地址 | 检查 |
|---|---|---|---|
| X | addr[10] | addr[9:0] | addr必须小于1600 |
| W | addr[7] | addr[6:0] | 8位地址0..255全部覆盖 |

每个bank先判断bad_access，再产生bank_read/bank_write。只有合法请求、rst_n为1且part匹配时，宏selected才为1。选中宏CEN=0；写时GWEN=0、WEN全0；读和待机时GWEN=1、WEN全1。两颗宏都接相同低地址和写数据，只有一颗实际执行操作。

同bank读写冲突或X越界时，两颗宏都禁用；下一个沿后access_error为1、rd_valid为0。没有非法请求的下一沿error清零。不同bank可并行读写。

## 时序逻辑和L1返回

每个bank保存三个状态：rd_valid、access_error、return_part。读请求被接受时更新part；非读拍保留part，但valid清零。读数据是宏Q经过组合mux的输出，没有额外数据寄存器。

以X同一个bank连续读1023、1024为例：

| 时刻 | 请求和状态 | 下游动作 |
|---|---|---|
| E0沿前 | 地址1023，rd_en=1 | 请求须满足建立时间 |
| E0沿 | 宏0接受读；wrapper寄存part=0、valid=1 | 此沿不能消费刚发出的请求结果 |
| E0到E1之间 | 宏访问延时后Q稳定；mux选宏0 | rd_valid变高不表示沿后零延时数据就稳定 |
| E1沿 | 可同时接受地址1024的新请求 | 下游采样上一笔1023的valid/data |
| E1到E2之间 | part更新为1，宏1的Q稳定 | 为下一次采样准备1024的数据 |
| E2沿 | 可继续读或空拍 | 下游消费1024的数据 |

因此“L1”是本沿接受、下一上升沿消费。当前请求只决定本次使能，保存的part决定返回mux。最终能否满足该时钟周期，需要官方宏时序与完整数据路径STA确认。

复位在上升沿清valid/error/part，复位期间组合控制禁止访问；数据内容不清零。下游也必须在复位时取消在途返回，不消费复位前请求。

## 接入计算核仍需什么

四个X bank可提供四项X，活动W槽的四个bank可提供四项W；但当前wrapper尚未负责把它们组成计算核要求的k/g顺序。后续供数控制需要安排地址、有效行、W槽选择和X复用，并应对计算核暂不能接收的情况。

没有ready或返回FIFO意味着请求一旦接受就会按期返回，不能用拉低后续rd_en撤销它。必须在发请求前确认接收空间，或由上层保存返回。bias可由活动槽号与核bias_addr组合选读。

## 验证和保留事项

[tb_storage_wrapper.v](../../../tb/memory/tb_storage_wrapper.v)在下一上升沿、DUT非阻塞更新之前检查上一笔返回，并用独立记分板核对；连续跨1023/1024及127/128可检出错误的当前地址mux。还覆盖槽隔离、冲突、越界、空拍、复位和bias；[统计和数据来源](README.md#验证结论与证据)。

正式使用仍需核对完整官方模型，特别是待机Q行为与读返回保持条件。当前未完成宏级正式仿真、150MHz STA、矩阵调度、结果块、ICB或SoC验收。

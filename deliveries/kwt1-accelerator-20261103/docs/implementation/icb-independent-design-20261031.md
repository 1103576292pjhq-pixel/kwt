# 独立ICB接口设计与验证计划

用户已授权修改不必要的旧接口字段，并完成ICB模块编写和验证。依据仅为指定E203框架的32位sysper接口及当前功能需求，保留计算/存储架构，不读取或兼容交接包实现。

已执行完成：[最终回归](../../verification/icb-20261031T224503-e273cf/README.md)，两个完整任务800块、50688项Y/flags逐项一致；4接口TB、4接口错误副本及控制/软件回归通过。发起者为TB、SRAM为合同模型，未运行E203 CPU或赛事平台。

## 控制接口修正

- 装载标量32位，X/W检查signed16符号扩展，bias直接signed32；去除运行时shift。
- op3位覆盖7类内部操作，tile4位覆盖16tile，index13位覆盖X6336项，row7/count7覆盖96/64，sequence9位覆盖400块。task32/layer4作为自定义会话身份，不称为赛事必需字段。
- 保留装载完整性、双槽保护、结果完整性及显式释放：这些有防止覆盖/错位的功能作用；不再有PAIR、legacy/fast或旧打包ACK格式。

## 模块职责

`kwt_icb_regs`接ICB、译码及配置/状态、保存本地响应，路由结果事务；`kwt_command_fifo`首版为一项待执行命令缓冲（最小解耦寄存器，非深度8或最优声明）；`kwt_result_access`转接读/释放，保持原结果模块的响应退休边界；`kwt_icb`仅连接三模块并引出内部控制端口，不例化计算/存储。

全局一次一笔ICB响应；不支持响应退休与下一请求同拍。完整寄存器写要求4字节对齐、wmask=1111，其他返回总线错误且无副作用。所有地址在一个256字节窗口内，默认0x11000000可参数化；该地址是SysPer窗口内开发选择。

命令缓冲满时提交返回错误，配置不变、命令不丢弃既有内容；CPU可先读取结果并释放空间后重试。结果访问不得被满命令缓冲阻塞。数据口每次一项，不做自动索引推进。接口内部命令操作仍表示初始化、写X、开W槽、写W、写bias、提交完整槽、开始任务，编码是本工程选择。

## 寄存器表（32位）

| 偏移 | 名称 | 访问与定义 |
|---|---|---|
| 00 | STATUS | R：bit0命令空间、1busy、2compute_done、3task_done、4fault、5结果有效、6读完、7abort_pending |
| 04 | TASK | RW：待提交任务身份32位 |
| 08 | LAYER | RW：低4位，其余位必须0 |
| 0c | TILE | RW：低4位，其余位必须0 |
| 10 | INDEX | RW：低13位，其余位必须0，语义范围由装载控制检查 |
| 14 | DATA | RW：完整signed32位图 |
| 18 | COMMAND | W：低3位op0..6，其余位0；成功入缓冲时完整快照上述字段 |
| 1c | ERROR | R：低8位任务错误码 |
| 20 | RESULT_TASK | R：队首结果task，空时0 |
| 24 | RESULT_META | R：row[6:0]置位0..6，tile[3:0]置位8..11，count[6:0]置位16..22，空时0 |
| 28 | RESULT_SEQ | R：低9位队首序号，空时0 |
| 2c | RESULT_CURSOR | R：低7位读取进度 |
| 30 | RESULT_DATA | R：低16位Y，其上3位flags，高位0；成功响应退休才推进一次 |
| 34 | ACK_TASK | RW：待释放task32 |
| 38 | ACK_SEQ | RW：低9位，其余0 |
| 3c | ACK_COUNT | RW：低7位，其余0 |
| 40 | ACK | W：数据必须1，以ACK_TASK/SEQ/COUNT快照请求释放；由结果模块验证匹配/已读完 |
| 44 | ABORT | W：数据必须1，接受沿发一次中止请求 |

STATUS与ERROR在fault/中止期间仍可读。中止期间和fault时拒绝装载提交及结果数据/释放，返回本地错误；ABORT可在fault时使用，中止已pending时重复ABORT返回错误。配置在中止时清除，已接受总线响应必须保留。另提供external_abort_req用于外部取消；CPU在一笔受阻响应未结束时不能并行发另一ICB命令。

实现核对补充：fault/中止期间所有普通配置写也拒绝；STATUS bit3记录曾达到task_done的事实，新BEGIN入缓冲、fault或ABORT清除，避免读取状态本身使实时排空条件不满足。bit1据此显示当前任务是否仍忙。实际外部task_done继续保留实时安全排空语义。

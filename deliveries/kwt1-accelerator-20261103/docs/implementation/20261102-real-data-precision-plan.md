# 当前数值模型的真实数据精度评测

用户要求开始测本科数值精度，允许使用本地原始音频与已处理数据。仅评价已确认的Q12/Q16/Q28、acc40、RNE16、sat16方案；不改RTL、不训练、不调尺度、不覆盖旧报告。

规范：赛题指南PDF第11页。本科指标是每层汇总全部样本输出后，以误差RMS除以max(浮点参考RMS,1e-8)，再取12层最大值，门槛0.03。不计算样本NRMSE的平均数替代该指标。

1. 核对现有221条验证缓存的manifest、50个数据文件哈希、源模型提交、checkpoint和220个音频哈希。当前软件数值模型重算12层，输出每层与最差单任务误差、裁剪/饱和计数、可复现报告。
2. 本地已有可用的Python3.8.20/TensorFlow2.4.0环境。复用个人旧工程中只读的kwt_reference/validation_references提取器，使用指定源模型实际重推理全部验证划分，定点计算只调用当前model/fixed_numeric.py。不运行旧数值候选评估器、不修改旧工程文件。
3. 完整验证保留原官方索引的样本重复权重，静音波形可只计算一次并按原索引multiplicity汇总。验证清单、音频哈希、运行配置和提取脚本哈希写入新目录。
4. 指标汇总器用独立手算测试覆盖样本能量不同、静音分母下限、加权重复、非有限值拒绝、真正3%边界；运行原有软件回归。
5. 输出新JSON/CSV/中文报告，明确属于本地验证集的软件数值精度，不冒称官方未公开600条评测、真实音频RTL或SoC测试。提取环境采用TF2.4.0代替原依赖2.4.0rc1，记录未证明等价这一限制。

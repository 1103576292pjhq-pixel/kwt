# 不含共享SRAM的加速器性能基线

用户授权直接继续测量现阶段指标。新增独立测试平台/统计工具，保持生产RTL、既有数值合同、功能测试和已通过记录不变。复用已通过的12层真实向量，不重复提取/标定数据。

## 计时合同

- 发起者是单请求ICB测试平台，不是E203。数据文件预读和结果黄金比较放计时窗外；所有实际ICB配置/参数/X/W/bias装载、状态轮询、等待、结果读取和正确ACK均在窗口内。
- 起点：本任务第一笔TASK配置写请求在ICB被接受的上升沿；终点：400个结果块完整读取且ACK后，CPU可读完成状态的STATUS响应退休沿。报告end-start周期，计数采用(start,end]边沿，避免off-by-one。
- 不做故意早ACK、故意忙命令写/错误重试、ABORT或随机延迟。COMMAND写前轮询ready，阻塞时服务结果。收到任何错误响应立即判失败。
- 总线访问的load/status/result/ack及TB空闲间隔为互斥分类，和必须等于总周期。core_busy/operand_group/output_stall为重叠观察量，不能与总线周期相加。
- 每任务记录第一次core启动、最后COMMIT命令被load-control队列接受、最后core完成、最后Y退休、最后ACK退休、完成响应，及400块/102400组/25344输出/400ACK计数。final_commit_cycle是接受沿，语义提交执行会晚一拍；该观察点不影响总计时边界。
- 仿真时钟为6.667ns（1ps取整，约150MHz）；统一折算用150MHz目标。折算不证明STA已满足150MHz。
- 峰值归一化利用率采用有效MAC数99*256*64 / (16*对应周期)。每组发射含4*4个乘法槽，但最后一行mask会产生padding，因此有效MAC数不按填充行100计算。

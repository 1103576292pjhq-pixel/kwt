# RTL学习笔记：本次点积开发中的常见问题

整理：2026-10-29。依据本对话已讨论的内容及当前点积源码补录，属于讲解笔记；实际接口和数值规则仍以源码、冻结合同及模块记录为准。

## 1. 64位输入为什么仍是一组数据

每组包含四个signed16的X和四个signed16的W，因此X、W各自需要64位总线。它不是一次输入四组时序事务，而是一次事务并排携带四个数。

```verilog
wire signed [15:0] x0;
assign x0 = in_x[0 +: 16]; // 第0项放最低16位
```

其余X位于[31:16]、[47:32]、[63:48]。4个X与4个W形成16个交叉乘积，lane=p*4+q。总线用于端口组织，内部是否使用数组可按可读性选择。

## 2. for、generate与“一个时钟沿只能写一个结果”

固定界限的可综合for通常展开硬件或并行赋值，不像CPU程序那样每轮自动消耗一个时钟周期。

```verilog
always @(posedge clk) begin
    if (clear) begin
        for (i=0; i<64; i=i+1)
            acc[i] <= 40'sd0;
    end
end
```

上面描述同一个沿清零64个寄存位置，不是循环64拍。是否用64个寄存器或其他存储结构，需结合读写行为及综合结果判断。

generate用于展开模块、独立always、wire或assign等结构；过程内for用于一个always中的重复操作。二者都可能描述并行硬件，但不保证综合结构完全相同。

真正要循环64拍，应有时钟驱动的计数器，每拍只推进一次计数。多次写同一寄存器的非阻塞赋值也不会自动形成跨拍迭代，应另行分析赋值优先级。

## 3. 非阻塞赋值与最后写回

```verilog
always @(posedge clk) begin
    a <= b;
    c <= a;
end
```

沿前a、b的值用于本次采样；沿后a获得旧b，c获得旧a，不会让c在同沿直接看到更新后的a。这也是最后输入握手、乘积寄存、累加写回和顶层响应done需要分清的原因。

组合计算一般用阻塞赋值`=`并覆盖所有输出分支；时钟寄存一般用非阻塞赋值`<=`。

## 4. 是否需要old_acc

当前累加器直接使用：

```verilog
assign lane_sum[LANE] = acc[write_addr] + product_ext;
```

old_acc如果仅是同一组合读值的别名，可以删除以简化阅读；这不表示旧累加值不再参与计算，也不一定减少综合资源。product_ext仍需保留32→40位符号扩展的语义。

## 5. valid、ready与背压

```verilog
wire fire = valid && ready;
```

在采样上升沿两者同时为1才传输。valid=1、ready=0时，发送方要保持valid及整组数据/标签；这就是背压。

乘法器、累加器没有ready，必须由控制器保证下游能接收每个有效乘积。顶层先完成有限块乘加，再逐项输出，因此下游暂停时可以保持结果，不需要让乘法流水中途受阻。

计数器只随真实fire推进。最后输入收完、最后acc写回、最后Y被接收、CPU确认读完是不同完成边界。

## 6. 三段式FSM

当前顶层分成状态寄存、组合next_state、组合控制译码；计数器和块元数据另有时序always。三段式并不要求整个文件恰好有三个always。

```verilog
always @(*) begin
    next_state = state;
    case (state)
        S_RUN: if (group_fire && input_last) next_state = S_FLUSH;
        // 其余分支见生产源码
        default: next_state = S_IDLE;
    endcase
end
```

这是结构片段，不能替代完整状态表。组合控制使用assign也是第三段；给输出额外加寄存器会改变时序，不能为统一格式随意添加。

## 7. timescale为什么TB中要明确写

```verilog
`timescale 1ns/1ps
reg clk = 0;
always #5 clk = ~clk;
```

时间单位1ns、精度1ps，#5表示5ns，时钟周期10ns。含延时或使用仿真时间的文件应明确时间设置，避免继承其他编译单元设置带来差异。

点积生产模块没有#延时，其寄存更新由输入clk决定，未写timescale；添加相同指令也不会改变这些模块的综合功能。后续外围文件已有timescale属于文件风格差异，不表示它们的硬件由此获得100MHz频率。

timescale不设置实际工作频率；硬件时序要通过时钟约束、综合和STA确认。TB中的#1采样等待只是避开仿真调度竞争，不是设计新增一级流水。

## 8. signed与位宽

切片后的位图应明确解释为signed；负乘积扩展到40位时，高位补符号位。acc与bias先扩展为41位再加，防止先回绕后丢失溢出信息。

40位有符号最小值的绝对值为2^39，放不进signed40正数范围，所以量化器的magnitude使用unsigned40。RNE不是简单截断或一律加0.5：+2.5→2、+3.5→4、−2.5→−2、−3.5→−4，之后再sat16。

## 9. 低有效同步复位

```verilog
always @(posedge clk) begin
    if (!rst_n) valid <= 1'b0;
end
```

这是同步复位，需要在上升沿采样到rst_n=0才更新寄存器。部分顶层组合握手又被rst_n门控，因此拉低复位可立即关闭端口valid/ready；这不等于内部寄存器采用异步复位。

大数据存储不必统一清零，先清valid/owner隔离旧数据；点积acc仍须在每块CLEAR时清零，不能把取消旧事务与准备新累加混为一件事。

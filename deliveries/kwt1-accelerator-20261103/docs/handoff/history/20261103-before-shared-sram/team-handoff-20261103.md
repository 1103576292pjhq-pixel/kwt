## 2. 架构与数值

单任务固定：`X[99,64] × W[64,256] + bias[256] → Y[99,256]`。十二层分别换参数执行十二项独立任务，不是片上执行整个Transformer。

| 对象 | 位宽/小数位 | 用途 |
|---|---|---|
| X | signed16 / Q12 | 输入矩阵 |
| W | signed16 / Q16 | 权重 |
| product | signed32 / Q28 | 精确16×16乘积 |
| bias | signed32 / Q28 | 与乘积相同尺度 |
| accumulator | signed40 / Q28 | 64项顺序累加 |
| 加bias临时值 | signed41 / Q28 | 保留加法进位后限幅到40位 |
| Y | signed16 / Q12 | RNE右移16，再sat16 |

flags：bit0原始值溢出、bit1输出饱和、bit2整个任务最后一项。合法K=64任务的累加及加bias范围可由40位覆盖，raw溢出不可达；组件测试仍覆盖转换器边界。没有48位累加器，也没有运行时可变shift。

计算结构：PM=4、PN=4、CTX=4，16个乘法器、64个40位累加上下文；每块4行×16列，每块256组操作数。每任务400块、25,344个有效输出、1,622,016次有效MAC；末行组只有3行有效。

内部X：8×1024×16宏，16KiB；内部W：16×128×16宏，4KiB，分双槽；bias为两槽共32项32位寄存器；另有双结果块。内部SRAM物理容量合计20KiB，与待接的512KiB平台共享SRAM是两个概念。CPU负责搬运，无DMA。

## 5. SRAM与E203状态

官方SRAM功能模式采用`ARM_UD_MODEL`，已通过配置为EMA=2、EMAW=0。**生产顶层默认EMA仍是0，复测/集成时须显式传2，不能以为默认值已改。**功能模式不证明物理时序。

历史SRAM时序模型运行曾出现hold违例和X结果，已知TB在CLK与控制同一时间戳变化，模型hold要求500ps。需要结合波形、激励时序及真实约束核查；未凭功能模式通过、改EMA或屏蔽检查宣称解决。

E203在独立副本`kwt-soc`中通过`prepare_kwt_soc.py`新增`kwt_soc_top`，连接SysPer ICB，并逐层引出已有总线时钟/复位。原`e203_soc_top`和原工程保留。加速器开发基址0x11000000不是正式平台最终地址；无中断，CPU轮询。固件镜像由本地已安装Nuclei 2024.06 GCC13.1.1构建，不必再次找编译器。

临时共享RAM控制器及仿真模型位于`integration/e203/shared_ram_dev/`，本地组件测试通过；按用户决定没有接入或上传至服务器活动SoC。其0xa0000000地址是假设，仿真数组不得综合。

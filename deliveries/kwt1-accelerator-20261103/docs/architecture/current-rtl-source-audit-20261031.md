## 当前源码中的可核查证据

- `rtl/include/kwt_control_config.vh`：注释“沿用现有ABI”，KWT_CMD_DATA_WIDTH=48，固定命令编码，KWT_RESULT_SEQUENCE_WIDTH=24。
- `rtl/control/kwt_load_ctrl.v`：原始48位合法性检查及BEGIN→OPEN→COMMIT→START流程。
- `rtl/control/kwt_result_blocks.v`：task/sequence/count ACK校验、响应游标，以及legacy/fast适配注释。
- `rtl/control/kwt_task_ctrl.v`：装载会话、结果发布和ACK排空控制接口。
- `rtl/memory/kwt_storage_array.v`：明确将SRAM接口规则归于用户提供的官方资料摘要；宏数量与bank组织为工程方案。

此前内部回归仍是其报告绑定源码、向量和测试合同的有效证据；它不验证所选命令ABI是赛事规范，也不证明设计参数最优。历史证据保留，不改写为赛方认证。

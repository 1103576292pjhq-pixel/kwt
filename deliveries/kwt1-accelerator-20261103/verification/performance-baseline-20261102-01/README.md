## 指标解释与验证

- 平均周期369614.75，按150MHz目标折算2.46409833ms/任务、405.827960任务/秒。
- 每任务核心忙碌155280拍（约1.0352ms），这是core_busy信号的累加，包含清零/乘加/排空/量化，不等于单纯MAC发射时间。核心忙碌占整个窗口约42.0113%。
- 有效MAC按99*256*64=1622016次，16个乘加通道；总窗口利用率约27.4275%，核心忙碌窗口利用率约65.2859%。最后行mask产生的填充乘法槽不算有效MAC。
- 12任务互斥分类合计：装载相关总线1655738拍，状态轮询606528拍，结果/描述符读取656256拍，ACK相关38400拍，TB事务间隔1478455拍。五项相加4435377；核心忙碌1863360拍与前述活动重叠，不应再相加。
- TB事务间隔是这个单请求激励器的固定节奏，已经单独列出；吞吐量代表这份已声明激励策略，不声称是加速器理论最大值或真实CPU速度。
- final_commit_cycle记录最后COMMIT命令被load-control队列接受沿；语义提交执行晚一拍。它只是观察点，总窗口仍到最终完成STATUS响应退休。
- 48项软件测试通过，实际ICB账本304128项逐位差异0且每任务NRMSE<=3%；故意破坏golden后在计时结束的比较阶段准确失败。当前生产RTL、TB和数值模型与运行前快照哈希一致。
- 独立只读审查无Critical/Important；SHA256校验87个包文件与压缩包均通过。实际包形状的python -S --help检查通过，不要求NumPy。

# 七项赛题技术报告

本工程用E203控制加速器完成KWT-1的前馈线性计算，并扩展到完整十二层PostNorm编码器。阅读时先掌握一笔点积如何变成硬件事务，再理解矩阵、注意力、单层与十二层调度。所有神经算术在RTL中完成，CPU负责命令与数据搬运。

本科必做为第1—3项；第4—7项是当前已批准的扩展。各篇使用赛题正式任务名，数学、代码、验证证据与正式验收缺口分开说明。

## 如何判断“通过”

数学结果对照、RTL逐位对照、真实CPU执行、generic结构综合和正式比赛验收是不同证据层级。报告中的本地通过只覆盖已完成的实际测试；正式平台、指定库与SRAM宏、150MHz、2.25mm²、综合后功能、功耗/能耗、600样本和组委会12个性能任务有各自待验状态。

本地硬件的实时完成门见[encoder状态](../../../work/encoder_status.json)和[验证总报告](../../../reports/encoder/verification/report.md)；技术报告本批状态见[报告状态](../../../work/report_cycle_status.json)。七项Markdown齐全不等于七项比赛要求全部通过。最终可引用结论以08中的根控接受记录和报告manifest为准。

现有输入覆盖包括3个原始工程输入与12类公开工程样本；它们不能替代组委会600样本精度或正式12个整机性能任务。当前整机复用实验使用同一输入、两策略各一次完整十二层。

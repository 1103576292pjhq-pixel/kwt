# 05 单层编码器

## 1. 任务目标与知识全景

单层编码器先通过注意力交换 token 之间的信息，再通过前馈网络变换每个 token 的特征；两次残差保留输入通路，两次 LayerNorm 控制每个 token 内的特征尺度。模块全部接通还不够，残差基底、归一化维度和浮点操作顺序必须与目标模型一致。

《2026赛题指南》印刷页 8 的第 5 项要求集成注意力、两处残差、两处 LayerNorm、64→256→64 前馈网络及 GELU，完成 **PostNorm** 编码器；按官方运算顺序验证单层结果，对照本设计的软件数值模型检查中间输出，并解释近似误差。第 5 项是研究生必做、本科生选做。本报告覆盖本工程选做实现。

| 本章核心概念 | 必须分清的关系 |
|---|---|
| X、A、R1、N1 | 注意力从 X 出发；先 `R1=X+A`，再 `N1=LN1(R1)` |
| FFN1、GELU、FFN2 | 特征宽度 64→256→64，逐 token 执行 |
| R2、Y | `R2=N1+FFN2`，再 `Y=LN2(R2)` |
| PostNorm | 每个子层的残差加法之后才归一化 |
| 三层正确性 | 数学/模型语义、C 的有限精度算法、RTL 对 C 位真分别核验 |

当前已有完整 99×64×256 RTL 逐层结果、全部 token 输出和阶段 trace。本报告描述这些局部证据及设计机制；七项整体最终接受以统一完成门和独立复核为准，也不能把工程子集推成正式分类精度通过。

## 2. 从输入到输出的完整公式

### 2.1 输入输出保持 99×64，隐藏层扩展为 99×256

X 是一个完整编码器的输入，不是旧 FFN1 测试中 LN1 之后的中间数据。生产尺寸 M=99、D=64、H=256；输入/输出各为 6,336 个 binary32 word，编码器一次处理全部 99 个 token。最终分类只选第 0 个 token 是后续分类头行为，不能据此省略其他 token；下一层 attention 仍依赖全序列。

| 阶段 | 公式/作用 | shape | trace ID |
|---|---|---:|---:|
| q、k、v | XWq、XWk、XWv，无 bias | 各 99×64 | 0、1、2 |
| scores | QKᵀ×0.125 | 99×99 | 3 |
| prob | 按 token 行做稳定 Softmax | 99×99 | 4 |
| context | PV | 99×64 | 5 |
| attn=A | context×Wo+bo | 99×64 | 6 |
| r1=R1 | X+A | 99×64 | 7 |
| n1=N1 | LN1(R1) | 99×64 | 8 |
| ffn1=F1 | N1W1+b1 | 99×256 | 9 |
| gelu=G | GELU(F1) | 99×256 | 10 |
| ffn2=F2 | GW2+b2 | 99×64 | 11 |
| r2=R2 | N1+F2 | 99×64 | 12 |
| y=Y | LN2(R2) | 99×64 | 13 |

注意力完整公式和逐行缓存见 [单头注意力模块](04_单头注意力模块.md)。其中 Q/K/V 没有 bias，Wo 有 bo；score 缩放固定 0.125。当前完整层的核心顺序是：

$$
A=\operatorname{Attention}(X),\quad
R_1=X+A,\quad N_1=\operatorname{LN}_1(R_1),
$$

$$
F_1=N_1W_1+b_1,\quad G=\operatorname{GELU}(F_1),\quad
F_2=GW_2+b_2,\quad R_2=N_1+F_2,\quad
Y=\operatorname{LN}_2(R_2).
$$

W1 为 64×256，W2 为 256×64；b1 为 256，b2 为 64。这里第二残差的基底是 **N1**，不能换成 X、R1 或单独 F2。两套 LN 的 gamma/beta 独立来自训练参数，不能互用，也不能默认 gamma=1、beta=0。

### 2.2 LayerNorm 对单个 token 的 64 个特征归一化

对输入的一行 u，LayerNorm 使用总体方差：

$$
\mu=\frac1D\sum_{j=0}^{D-1}u_j,\quad
c_j=u_j-\mu,\quad
v=\frac1D\sum_{j=0}^{D-1}c_j^2,
$$

$$
\operatorname{LN}(u)_j=\gamma_j\left(c_j\cdot\frac1{\sqrt{v+\epsilon}}\right)+\beta_j,
\qquad \epsilon=10^{-6}.
$$

μ、v、倒标准差是每个 token 各自计算的标量；gamma/beta 则按特征索引共享于 99 行。方差除以 D，不能用样本方差的 D−1；epsilon 在方差之后、开方之前相加，不能加到标准差或除法结果上。官方三维张量为 `[B,T,D]`，LN 作用于最后的 D 维。

RTL 的精确顺序为：从 +0 左到右 ADD 求和 → MUL 1/D → 每特征 SUB 居中 → 从 +0 左到右 FMA(c,c,acc) 累积平方 → MUL 1/D → ADD epsilon → SQRT → DIV(1,std) → 每特征 MUL(c,invstd) → FMA(normalized,gamma,beta)。D=64 时 1/D 为 `0x3c800000`；epsilon 冻结为 `0x358637bd`。先求 `E[u²]−E[u]²` 或把 affine 拆成 MUL+ADD 都会改变当前位真契约。

epsilon 防止常量行的零方差导致除零，但不意味着 LN 能修复任何非法输入。core 发现非有限中间结果会 fault，不能依赖后面 LN 把它“归一化回来”。

### 2.3 GELU 用固定 tanh 近似，官方仍是 erf

官方精确 GELU 为：

$$
\operatorname{GELU}_{erf}(x)=\tfrac12x[1+\operatorname{erf}(x/\sqrt2)].
$$

当前软件数值模型和 RTL 固定使用：

$$
u=\sqrt{2/\pi}\,(x+0.044715x^3),\quad
\operatorname{GELU}_{tanh}(x)=\tfrac12x[1+\tanh u].
$$

为避免直接计算大正指数及负数分支的严重相消，实现先计算 `e=exp_neg(−2|u|)`，再采用稳定分式：

$$
G(x)=\begin{cases}
x/(1+e),&x\ge0,\\
xe/(1+e),&x<0.
\end{cases}
$$

| 运算顺序 | 当前 FP32 实现 |
|---|---|
| 三次项 | `a=MUL(x,x)`，`b=MUL(a,x)` |
| 近似参数 | `c=FMA(0.044715,b,x)`，`u=MUL(0.7978845608028654,c)` |
| 指数输入 | `z=MUL(abs(u),−2)`；复用 attention 的 exp_neg |
| 分式 | `den=ADD(1,e)`；负分支先 MUL(x,e)，最后 DIV |
| 快速边界 | 有限且 abs(x)≥10：正数返回 x，负数返回 −0；z≤−80 时 e=+0 |

这些边界和常数由 [encoder_nonlinear.sv](../../../rtl/encoder_nonlinear.sv) 与 [encoder_ref.c](../../../numeric/encoder/encoder_ref.c) 共同冻结。该设计没有实现一般 tanh/erf 单元。近似公式与官方 erf 的差异必须单列；RTL 与 C 逐位零差只证明实现了这套近似算法。

## 3. 架构和选择理由

### 3.1 先准备 K/V，再逐 token 完成后半层

```text
完整 X + 当前层 49,792-word 参数
 → 完整 K RAM / 完整 V RAM
 → 第 i 行 Q → 一行 score/prob → context_row → Wo+bo
 → tmp 保存 attention → 与 X 第 i 行相加，得到 R1
 → LN1：tmp 居中，得到 n1[64]
 → n1×W1+b1 → 每个隐藏分量立即 GELU，写 hidden[256]
 → hidden×W2+b2 → tmp[64]
 → tmp+n1 → LN2 → 写输出银行 Y 第 i 行
 → 下一行，直至 i=98 的第 63 个特征写完
 → done → READ_Y 全部 6,336 word
```

当一行 Y 已经写出时，后续 query 的注意力仍使用原 X 生成的完整 K/V。所有输出写入另一激活银行，所以不会覆盖仍用于第一残差的原 X。当前行的 N1 保留到第二残差结束，不额外保存完整 99×256 hidden 或完整 N1 矩阵。

| 模块/对象 | 实际职责 | 为什么这样分工 |
|---|---|---|
| [encoder_core.sv](../../../rtl/encoder_core.sv) | 循环、阶段、同步存储地址、残差/LN/FFN 调度 | 用显式状态保持模型顺序，便于定位第一个错误阶段 |
| [encoder_fp32.sv](../../../rtl/encoder_fp32.sv) | 单笔 binary32 请求响应，HardFloat 运算部件 | 统一舍入、异常和响应背压；DIV/SQRT 脉冲响应先缓冲 |
| [encoder_nonlinear.sv](../../../rtl/encoder_nonlinear.sv) | exp/GELU 微程序，复用 FP32 接口 | 非线性仍由可综合 FP32 操作构成，C 只作验证参考 |
| [encoder_sync_ram.sv](../../../rtl/encoder_sync_ram.sv) | 同步读、同步写，不清数据阵列 | 大块数据不接逐位复位，控制器维护装载有效性 |
| weights_ram | 49,792 word | 一次装当前层，下一层按命令更新 |
| x0、x1 | 各 6,336 word | 输入和输出隔离，支持后续层内部交换 |
| keys、values_ram | 各 6,336 word | 全 query 复用完整 K/V |
| q/context_row/tmp/n1 | 各 64 word | 当前行暂存，tmp 被 R1、居中值、FFN2、R2 复用 |
| score/prob、hidden | 99+99+256 word | 行级注意力和单 token 的 FFN 隐藏层 |

五块大 RAM（单层权重及两块激活、K/V）共 300,544 B 的逻辑数据容量；所列行级数组共 2,840 B，均按 32 bit word 推导，不含标量控制寄存器。这是 RTL 存储声明容量，不能直接等同芯片面积。同步 RAM 尚未映射正式 SRAM macro，也不能把内部容量和外部 512 KiB 共享 SRAM 当成同一存储。

顺序实现的取舍是降低控制与并发复杂度，让每次 FMA 顺序可核查；代价是 core 计算周期长。没有根据源码之外的信息宣称多通道并行、满流水、确定吞吐或最优面积。后续改变并行归约、分块或数值格式，必须同时维护参考和验证契约。

### 3.2 状态机把张量生命周期写成可核查规则

每个基本操作执行 `step0` 准备同步读地址、`step1` 在 ready 时提交、`step2` 等待结果；只有 `finish_op` 才推进主 phase。非线性 phase 把共享 FP32 通路交给微程序，其他 phase 由 core 直接发请求。一个接口上的请求不会与另一个阶段并行抢占。

| 阶段 | 关键状态及行为 | 下一阶段/生命周期 |
|---|---|---|
| 注意力 | PK/PV 后，每行 PQ→PSCORE/PSCALE→PDELTA/PEXP/PSUM→PPROB→PCTX→PATTN/PBO | PBO 写 tmp；完整层继续 PR1，独立 attention 才写 A 并提前结束 |
| 第一残差 | PR1：tmp[col]+X[row,col] | 得到 R1 后，total=+0、second_norm=0 |
| 均值 | PLSUM 逐特征加；PLMEAN 乘 1/D | mean 保存，acc=+0 |
| 方差 | PLCENTER 计算并覆盖 tmp；PLVAR 对 center 做 FMA 平方和 | PLVMUL 除 D，再 PLEPS 加 epsilon |
| 归一化 | PLSQRT→PLINV→PLNMUL→PLAFF | 生成 LN1 的 n1；或 LN2 的 Y |
| FFN 第一层 | PFF1：n1[k]×W1[k,col]，k=0..63；PBH 最后加 bias | trace FFN1 后立即 PGELU，hidden[col] 被 GELU 结果覆盖 |
| FFN 第二层 | hidden 全 256 个分量就绪后，PFF2 按 k=0..255 累加；PB2 加 bias | tmp 保存 F2，转 PR2 |
| 第二残差 | PR2：n1[col]+tmp[col] | 得到 R2，total=+0、second_norm=1，再复用 LN 状态 |
| 输出 | 第二次 PLAFF 写 Y 的 rowD+col | 最后一行写满才 done；否则 row++ 转 PQ |

LN 的 beta 与 gamma 共用权重单读端口：PLNMUL 读取 beta，在其乘法响应到达时锁存为 `center`；下一 PLAFF 读取 gamma，执行 `FMA(scaled,gamma,beta)`。这里 `center` 被复用为 beta 锁存器，不能只看变量名就误认为仍在做居中减法。若省掉 beta 预取或在错误拍锁存，算术部件正确也会产生错误归一化结果。

## 4. 权重布局和事务契约

### 4.1 一层共有 49,792 word

| 参数 | shape | 起始 word | RTL 名称/地址 |
|---|---:|---:|---|
| Wq、Wk、Wv、Wo | 各 64×64 | 0、4096、8192、12288 | WQ/WK/WV/WO+k×D+col |
| bo | 64 | 16384 | BO+col |
| LN1 gamma | 64 | 16448 | G1+col |
| LN1 beta | 64 | 16512 | B1+col |
| W1 | 64×256 | 16576 | W1+k×H+col |
| b1 | 256 | 32960 | **BH**+col |
| W2 | 256×64 | 33216 | W2+k×D+col |
| b2 | 64 | 49600 | B2+col |
| LN2 gamma | 64 | 49664 | G2+col |
| LN2 beta | 64 | 49728 | BN2+col |

长度公式是 `4D²+2DH+H+6D=49792`，即 199,168 B。RTL 的 `B1` 表示 LN1 beta，FFN 的 b1 段叫 `BH`，两者不可按名字混同。所有矩阵都按 `[input_feature,output_feature]` 行优先打包。真实语义取参和布局源见 [encoder_export.py](../../../model/encoder_export.py) 与 [contracts.py](../../../numeric/encoder/contracts.py)。

### 4.2 一层完成和十二层完成不同

从新任务启动一层：`BEGIN_JOB → 连续 LOAD_X → 连续 LOAD_W → START(data=0) → 等待 done → READ_Y`。启动必须检查 6,336 个输入和 49,792 个权重全部有效、层号正确、尚未 done/fault。done 只表示当前层全部输出写完；layer 0 的单层运行不置 job_done，只有 layer_index=11 的完整层完成才置 job_done。

完整层 done 后，layer_index<11 时可用 SWAP 翻转输入/输出银行，保留全部激活并清本层权重计数；也可用 RELOAD 清输入计数，要求 CPU 完整回读和重装。两种模式的逐层调度及已批准比较由 [公共接口](../interface.md) 和十二层报告说明。本报告不把首层通过外推为所有层参数调度通过。

busy 时所有 core 命令拒绝而不打断计算；READ_Y 使用同步读等待状态返回另一银行的数据，响应阻塞保持。复位撤销在途操作与有效计数，RAM 内容不清；BEGIN_JOB 或复位后须重新完整装载。非有限结果或算术错误终止运算并置 fault，五位 flags 累计保留。本层 `cycles` 从启动后 busy 区间计数，和含 CPU/host 装载、等待、写回的端到端周期分列。

## 5. 验证方法：模型、数值、RTL 分层闭环

### 5.1 官方导出确定“算的是什么”

[官方模型语义核对](../../../reports/encoder/research/model-semantics.md) 记录：单头、PostNorm、两套 LN 参数、epsilon=1e−6、QKV 无偏置、GELU 为精确 erf。官方实际运行关闭训练/dropout，完整输入输出为 `[99,64]`。

[encoder_export.py](../../../model/encoder_export.py) 观察原完整模型实际张量，返回原张量，未另建一套“看起来等价”的神经运算替代官方结果。它逐项核对 162 个 live 张量、607,308 个标量的 checkpoint 恢复值，检查每层 Y 逐位进入下一层输入，实际末层 CLS 经原分类对象重放的 logits 与完整模型原输出相同。每层的 13 个参数按语义属性映射打包，不按 Dense 显示名或变量数组偶然顺序猜测。

### 5.2 独立 C 确定“有限精度到底怎样算”

[encoder_ref.c](../../../numeric/encoder/encoder_ref.c) 独立实现全部 14 阶段，没有调用 RTL，也没有由 RTL 输出生成期望。所有 dot 从 +0 开始左到右 `fmaf`；bias 最后 ADD；普通算术每次 binary32 舍入。编译选项包含 `-ffp-contract=off -fno-fast-math`，运行检查最近偶数舍入。C 输出同时与官方张量比较 NRMSE/最大绝对差，与 RTL 比较则必须逐原始位相同。

独立复跑相同 C 实现证明复现性，不能充当第二个算法。额外的 Fraction/整数 RNE oracle 只重算两个小 fixture：14 阶段共 372 word，位差 0；C 单元测试 14 项、4 个可编译行为变异，以及 1×1×1、3×4×8、99×64×256 sanitizer 检查均有记录，见 [参考验证报告](../../../reports/encoder/reference/VERIFICATION.md) 和 [exact-oracle.json](../../../reports/encoder/reference/tests/exact-oracle.json)。C 支持的部分小尺寸并非 RTL 当前参数范围，不能把 sanitizer 尺寸当成硬件覆盖。

### 5.3 公开输出、阶段 trace、文件回读同时验

TB 在 done 后经 READ_Y 读全部 6,336 word，每个 word 与参考 `y.hex` 比较，再落盘；Python 对完整输出文件再次比较。trace 独立检查 14 个 stage 的地址、值、重复项和数量。期望 hex 与 NPY/bin 互校，并绑定正式 manifest 的已发布摘要；现场给可疑文件重新计算一个 SHA 不能证明内容正确。

[run_encoder.py](../../../dv/encoder/run_encoder.py) 记录来源、编译源、input、参考 manifest、binary、build key、日志与输出摘要，并在运行前后核对未改变。每例 PASS 要有实际执行退出 0 和完整 marker，不能由旧日志、只编译成功、只跑 `--help` 或部分输出替代。

### 6.2 近似误差在哪里出现

误差指标使用 `RMSE=sqrt(mean((C−TF)²))`，`NRMSE=RMSE/max(sqrt(mean(TF²)),1e−8)`；最大绝对差反映最坏单点，NRMSE 反映相对整体尺度，二者都不能直接换算成分类错误率。

| 首个原始输入 layer_00 阶段 | C 对官方最大绝对差 | NRMSE | 可以据此判断的事实 |
|---|---:|---:|---|
| q/k/v/scores | 0 | 0 | 本具体层这四类张量逐位相同 |
| attention | 1.3411045074×10⁻⁷ | 1.0642551144×10⁻⁷ | Softmax/浮点路径之后有小差异 |
| LN1 | 1.1920928955×10⁻⁶ | 1.2604277192×10⁻⁷ | 归一化后仍非官方逐位目标 |
| GELU | 4.7322921455×10⁻⁴ | 4.6224347949×10⁻⁴ | tanh 对 erf 的近似差清晰可见 |
| FFN2 | 6.0486793518×10⁻⁴ | 4.2271370155×10⁻⁴ | 后续线性层可传播/放大局部差 |
| 最终 Y | 4.1904300451×10⁻⁴ | 1.0187336804×10⁻⁴ | 残差/LN 改变误差分布，不能简单逐项相加 |

数据来自 [reference manifest](../../../reports/encoder/reference/manifest.json) 的首个样本 `layer_00/comparisons`。它们是该算例观察，不是所有样本的全局误差上界；也不能把全部差异只归因于 GELU，因为 Softmax 近似和浮点表达式次序亦有影响。

| 固定公式检查/最终比较 | 已有结果 | 边界 |
|---|---|---|
| exp_neg 对 double exp | 100,001 点，最大相对差 7.0829376545×10⁻⁸ | 区间采样与固定公式验证 |
| tanh GELU 对精确 erf | 40,001 点，[-10,10]；max_abs=0.0004734134403，RMSE=0.0001559762095 | 非参数搜索、非训练拟合，不是端到端误差界 |
| 原三输入12层最终 Y 对官方 | 最大 NRMSE=0.0004071640494 | 与官方预测相同 3/3 |

最终比较来源为 [参考验证报告](../../../reports/encoder/reference/VERIFICATION.md)、[test12 manifest](../../../reports/encoder/reference-test12/manifest.json) 和 [参考交接](../../../work/encoder_reference_handoff.json)。12/12 是与官方预测一致，silence 的真实标签并未被正确分类；不能写成 12/12 分类正确，更不能外推正式 600 样本 Top1 下降≤2个百分点。

### 6.3 状态、复位和负测覆盖

小规模协议测试覆盖缺载、错误顺序/层号、忙时拒绝、完成前/越界读取、同步读等待和响应背压。完成门短测另包含中途复位、故障后完整重装、总线非法事务等路径，见 [检查记录](../../../reports/encoder/verification/checks/status.json)。[RTL 数值变异](../../../reports/encoder/verification/mutations/status.json) 的错误 score scale、LN bias 和漏末 token 均编译成功后被实际 word mismatch 捕获，表明检查不会只看一个 CLS 或一个 done 信号。

当前基础 FP32 的 recoded→IEEE 边界精确识别零、无穷、NaN 类；符号零保持，未知分类继续四态传播。DIV/SQRT 的脉冲响应被锁存并保持至消费。已有 34 组定向×两模拟器×两轮共 136 个无暖机全新进程，以及 21,291 事务主测试，详见 [FP32 交接](../../../work/fp32_handoff.json)。这解释当前零输入 GELU/LN 所依赖的机制和证据，不把二态模拟器的零值默认行为当作四态正确性证明。

## 7. 小例子与带答案的自检

### 7.1 用一行算清两次残差和 LN

取教学用 D=4，X=`[1,2,3,4]`，假设 attention 输出 A=`[1,0,−1,0]`，则 R1=`[2,2,2,4]`。令第一套 gamma 全 1、beta 全 0：μ1=2.5，居中值为 `[−0.5,−0.5,−0.5,1.5]`，总体方差为 `(0.25+0.25+0.25+2.25)/4=0.75`。

加入 epsilon 后，倒标准差约为 1.15469977，因此 N1≈`[−0.57734988,−0.57734988,−0.57734988,1.73204965]`。这一步说明 LN 的对象是一行特征；没有把其他 token 参与均值。

再设 FFN 的 W1、b1、W2、b2 全零，则 F1=0、GELU(0)=0、F2=0；第二残差是 R2=N1，而不是重新回到 X。若第二套 gamma 也全 1、beta 全 0，LN2 会再次按 N1 的实际方差与 epsilon 计算，结果非常接近 N1，但不能认为原始位必定完全相同。这是公式手算例，未冒称已有官方 fixture；精确 hex 仍由冻结 FP32 操作顺序给出。

### 7.2 自检题与答案

| 自检 | 答案/合格判据 |
|---|---|
| PostNorm 两个“Norm”各放哪里？ | `LN1(X+Attention(X))` 和 `LN2(N1+FFN(N1))`；能写出两处正确残差基底。 |
| LN 的样本数是 99 还是 64？ | 每个 token 内对 64 个特征算均值/总体方差；99 行分别处理。 |
| FFN 第一层只读取 X 的一行吗？ | 读取 LN1 输出 n1 的一行 64 特征，再映射到 256；不直接读取原 X。 |
| FFN bias 能预放进 dot 的 acc 吗？ | 本位真契约不允许；acc 从 +0 起，点积完成后最后 ADD bias。 |
| 为什么 beta 在 PLNMUL 读，gamma 在 PLAFF 读？ | 权重 RAM 单读端口；先利用乘法阶段预取 beta，再读取 gamma 做 FMA。 |
| 一个全零行是否应该 fault？ | 正常参数和有限计算下不应。方差为零但 epsilon>0；零值 GELU 和响应必须正确。 |
| 首例14阶段全对，是否证明180层每阶段都存了trace？ | 不能。180层有全部 Y 证据；首例12层另有全阶段trace，两类覆盖分别报告。 |
| RTL 对 C 零位差能证明官方精度指标吗？ | 不能。C 含固定近似，须另与官方比较并完成正式样本分类验收。 |

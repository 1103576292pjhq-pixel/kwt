# Verilator 系统执行告警审查

本次使用 `--binary --timing` 生成并执行 C++ 仿真程序，不把 lint 结果算作系统执行。编译真实退出码必须为 0；任何 `%Error`、编译失败、运行断言、CPU TRAP、非零 main 返回、缺项或超时都会阻止 PASS。完整原始告警保存在 `compile-verilator-3x4.log` 与 `compile-verilator-99x256.log`。

| 告警 | 数量（完整尺寸编译） | 位置及本批处理 |
|---|---:|---|
| PINMISSING | 80 | 公共薄壳没有连接的外部 pad 输出、禁用的外部 TCM 响应输出及不用的 SysFIO 请求输出。CPU 所需输入已接固定值或真实响应；保留原薄壳，实际启动及驱动执行验证其当前接法。 |
| LATCH | 15 | 全部来自上游 `e203_clkgate.v:44` 的低电平透明门控使能锁存器。属于原有时钟门控模型，本批不改写。 |
| UNOPTFLAT | 2 | 上游 BIU ICB ready 组合路径和未使用的 QSPI 仲裁路径。保留模型，以两种仿真器小矩阵周期/数据/事务一致及完整案例实际执行作为本批动态证据；不据此宣称所有外设或所有工作模式已验证。 |
| CASEINCOMPLETE | 12 | 上游 GPIO、I2C、PWM、JTAG、UART、SPI 外设的 case 覆盖提示。本批固件不使用这些外设，不把当前结果扩展为这些外设的功能验收。 |
| WIDTHEXPAND / WIDTHTRUNC | 37 / 3 | 上游原有宽度转换；本批未修改官方文件。新的系统测试台已消除自身隐式宽度告警。 |

`-Wno-fatal` 只允许上述原有 warning 被保留，错误与运行失败仍按非零退出拒绝。它不表示这些提示在所有用途下均可忽略，不构成综合、CDC、时序或物理签核。

本轮调试还实际捕获并修正了三个工程问题：freestanding GCC 对局部聚合初始化生成 `memcpy`（改为静态只读回调表）；两种工具的 `-I` 选项拼接方式不同（Verilator 使用连接路径形式）；flags 文本 `%02x` 的格式宽度差异（改为明确 `%08x`，再运行两种仿真器比对）。失败日志和格式差异文件按 `red-*` 保留，它们是负证据，不能代替最终通过结果。

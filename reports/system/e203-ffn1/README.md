# E203 执行 FFN1 驱动：验证报告

标准命令执行通过。真实公共 E203 CPU 从 ROM 启动到 ITCM，执行 freestanding C 生产驱动，完成一个默认 `99×64` 乘 `64×256` 加偏置案例，并在新仿真进程独立复跑。两个进程分别逐项检查全部 **25,344 项数值和 25,344 个 flags**，全部与冻结整数参考一致。

案例：`eight_750e3e75_nohash_0/layer_01`。仅此一个完整 CPU 案例，不把桥或原核心的 36 案例计为 CPU 36 案例。完整机器结果见 [result.json](result.json)，确切命令、工作目录、真实退出码和耗时见 [commands.jsonl](commands.jsonl)。
